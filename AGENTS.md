# Project: Soccer Coaching Platform

## Project Overview

This project is a web application designed to help youth soccer coaches manage their teams, create personalized training sessions, and organize their team schedule.

The application will eventually support:

- Team profiles including age group, skill level, and player count
- Practice scheduling and duration management
- A searchable soccer drill database
- Match results and performance observations
- Practice history and progress tracking
- Personalized practice recommendations

## Technology Stack

- Frontend: React
- Backend: Python with FastAPI
- Database: SQLite initially, potentially PostgreSQL later
- Version Control: Git and GitHub

Do not introduce additional frameworks or major dependencies without explaining why they are necessary.

## Development Philosophy

Follow these rules:

1. Do not build entire features or multiple milestones unless explicitly requested.
2. Break complex work into small, independently testable tasks.
3. Before implementing a significant change, explain the proposed approach.
4. Explain unfamiliar concepts and important design decisions.
5. Prefer straightforward, readable code over unnecessarily complex solutions.
6. Do not add functionality beyond the current task.
7. Preserve existing functionality when making changes.
8. When appropriate, suggest what the developer can implement independently.
9. Ask for approval before making major architectural changes.
10. Do not automatically move on to the next task after completing the current one.

## Workflow

For each development task:

1. Review the relevant existing code.
2. Explain what needs to be accomplished.
3. Identify the files that need to change.
4. Implement only the approved scope.
5. Run relevant tests when available.
6. Summarize the changes and explain how to test them.
7. Stop and wait for the next instruction.

## Current Development Priority

Focus on the foundational team management functionality.

The first milestone is to allow a coach to create, view, and edit a team profile.
